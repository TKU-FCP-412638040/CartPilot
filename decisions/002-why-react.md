# 決策卡 2：為什麼用 React 而不是 Vue

- 問題：選前端框架
- 選項：Vue（已熟）、React、Angular
- 取捨：Vue 最快、風險最低，但這個專案的目的是擴充技能，用熟的框架學習幅度最小。React 要多花時間學生態與寫法，還要同時學後端與 AI，進度風險較高；但元件、狀態、路由的概念與 Vue 相通。Angular 沒有深入評估，不列入
- 選擇與理由：選 React。這個專案的目的是擴充技能，並證明我能把前端能力遷移到另一個框架。Vue 仍是我的強項，這不是否定它。職缺抽樣中 React 較常出現，只當次要佐證，因為樣本小
- 何時會改：前兩週因學 React 落後超過 3 天，先改用現成元件庫減輕負擔；仍落後再評估改回 Vue
